## Acerca del proyecto

La **Landing Page de PlantSync** es la carta de presentación pública de **NaturaTech**. Su objetivo es comunicar de forma clara, visual y directa cómo la plataforma transforma el cuidado cotidiano de plantas mediante recordatorios inteligentes, diagnóstico asistido por visión e integración con sensores conectados.

A diferencia de la aplicación principal, este repositorio está enfocado exclusivamente en **captación, claridad narrativa y conversión** hacia la web app o su entorno de demostración interactiva.

## Secciones principales

| Sección | Propósito |
|---|---|
| **Hero & Propuesta** | Presentación principal del producto con llamadas a la acción directas hacia el registro y la demo. |
| **Beneficios y Funciones** | Resumen visual de las capacidades clave: gestión de jardín, diagnóstico con IA, telemetría IoT y retos. |
| **Cómo funciona** | Recorrido simplificado en pasos para que cualquier usuario entienda la experiencia antes de crear su cuenta. |
| **Identidad y Equipo** | Información institucional sobre **NaturaTech**, créditos visuales y enlaces al ecosistema completo. |
